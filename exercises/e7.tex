\begin{recap}
    \topic{Making decisions}
    \emph{Markov decision processes.} A \term{Markov decision process} (MDP) is a tuple $(\mathcal{S}, \mathcal{A}, P, R)$ such that
    \begin{itemize}
        \item $\mathcal{S}$ is a set of \term{states} $s$;
        \item $\mathcal{A}$ is a set of \term{actions} $a$;
        \item $P$ is a (stationary) \term{transition model} such that $P(s' \mid s, a)$ denotes the probability of reaching state $s'$ if action $a$ is done in state $s$;
        \item $R$ is a \term{reward function} that maps immediate (finite) reward values $R(s)$ obtained in states $s$,
    \end{itemize}
    and $0 < \gamma \leq 1$ is the \term{discount factor}.

    \emph{Utilities and policies.} The \term{discounted utility} of a reward sequence is $V([r_0, r_1, r_2, \ldots]) = r_0 + \gamma r_1 + \gamma^2 r_2 + \ldots$, which is additive for $\gamma = 1$. A \term{policy} $\pi : \mathcal{S} \to \mathcal{A}$ maps states to actions, and the expected utility obtained by executing $\pi$ starting in $s$ is
    \[
        V^\pi(s) = \mathbb{E}\left[\sum_{t \geq 0} \gamma^t R(s_t) \mid s_0 = s, \pi \right].
    \]
    The \term{optimal policy} $\pi^*$ maximizes the expected utility, and the \term{value} of a state is $V(s) = V^{\pi^*}(s)$. Then, $\pi^*(s) = \arg \max_a \sum_{s'} P(s' \mid s, a) V(s')$.

    \emph{Bellman equation.} The utility of a state is the immediate reward for that state, plus the expected discounted utility of the next state, assuming that the agent chooses the optimal action:
    \[
        V(s) = R(s) + \gamma \max_a \sum_{s'} P(s' \mid s, a) V(s').
    \]
    When the reward depends on the transition, $R(s, a, s')$, it moves under the sum: $V(s) = \max_a \sum_{s'} P(s' \mid s, a) [R(s, a, s') + \gamma V(s')]$.

    \emph{Value iteration.} Starting from initial estimates $V_0(s)$, \term{value iteration} repeats the \term{Bellman update}
    \[
        V_{i+1}(s) = R(s) + \gamma \max_a \sum_{s'} P(s' \mid s, a) V_i(s')
    \]
    until convergence. It converges to the unique solution of the Bellman equations whenever $\gamma < 1$, and also for $\gamma = 1$ when every policy reaches a terminal state.

    \emph{Policy iteration.} \term{Policy iteration} alternates \term{policy evaluation}, which calculates $V_i = V^{\pi_i}$ by solving the linear equations $V_i(s) = R(s) + \gamma \sum_{s'} P(s' \mid s, \pi_i(s)) V_i(s')$, and \term{policy improvement},
    \[
        \pi_{i+1}(s) = \arg \max_a \sum_{s'} P(s' \mid s, a) V_i(s').
    \]
    \term{Modified policy iteration} replaces the exact evaluation by a few simplified Bellman updates $V_{i+1}(s) = R(s) + \gamma \sum_{s'} P(s' \mid s, \pi_i(s)) V_i(s')$.

    \emph{Partially observable MDPs.} When the state is not observed, the agent collects percepts $e$ through a sensor model $P(e \mid s)$ and maintains a \term{belief state} $b$, a distribution over states. After doing $a$ and perceiving $e$, it becomes
    \[
        b' = \alpha \mathbf{P}(e \mid S') \sum_s \mathbf{P}(S' \mid s, a) b(s).
    \]
    The optimal action depends only on $b$: a POMDP is an MDP over belief states, with the reward $\rho(b) = \sum_s b(s) R(s)$.

    \topic{Reinforcement learning}
    \emph{Reinforcement learning.} In \term{reinforcement learning}, the transition model $P(s' \mid s, a)$ and the reward function $R(s)$ are unknown: the agent learns from trials, whose trajectories are sequences of transitions $(s, r, a, s')$, each holding a state, its reward $r = R(s)$, the action done and the next state. In \term{passive RL}, the policy $\pi$ is fixed and the agent learns the utilities $V^\pi(s)$; in \term{active RL}, it learns the optimal policy $\pi^*$. A \term{model-based} agent estimates $\hat{P}(s' \mid s, a)$ and $\hat{R}(s)$ from experience and solves the resulting empirical MDP. A \term{model-free} agent does not; for instance, \term{direct utility estimation} approximates $V^\pi(s)$ by the sample average of the observed rewards-to-go from $s$.

    \emph{Temporal-difference learning.} \term{Temporal-difference} (TD) \term{learning} updates $V^\pi(s)$ each time the agent experiences a transition $(s, r = R(s), a = \pi(s), s')$, to better agree with the Bellman equations for a fixed policy:
    \[
        V^\pi(s) \leftarrow V^\pi(s) + \alpha (r + \gamma V^\pi(s') - V^\pi(s)),
    \]
    where $\alpha$ is the \term{learning rate}.

    \emph{Exploration.} An agent that always acts greedily with respect to its current estimates may never discover better actions. An \term{$\epsilon$-greedy} agent acts randomly with a small probability $\epsilon$ and follows its current policy otherwise. An \term{exploration function} $f(v, n)$, such as $f(v, n) = v + K/n$, instead makes the agent optimistic about the actions it has tried $n$ times only, in $V^+_{i+1}(s) = R(s) + \gamma \max_a f\left(\sum_{s'} P(s' \mid s, a) V^+_i(s'), N(s, a)\right)$.

    \emph{Q-Learning.} The \term{state-action-value} $Q(s, a)$ is the expected utility starting out having taken action $a$ from $s$ and thereafter acting optimally, so that $V(s) = \max_a Q(s, a)$ and $\pi^*(s) = \arg \max_a Q(s, a)$. \term{Q-Learning} learns it in a model-free fashion, by updating $Q(s, a)$ each time the agent experiences a transition $(s, r, a, s')$:
    \[
        Q(s, a) \leftarrow Q(s, a) + \alpha (r + \gamma \max_{a'} Q(s', a') - Q(s, a)).
    \]
    It converges to the optimal Q-values, even when acting suboptimally, provided it explores enough. In \term{approximate Q-Learning}, $Q(s, a) = w_1 f_1(s, a) + \ldots + w_d f_d(s, a)$ is a linear model of features $f_k(s, a)$, and the update becomes $w_k \leftarrow w_k + \alpha (r + \gamma \max_{a'} Q(s', a') - Q(s, a)) f_k(s, a)$.
\end{recap}

\titledquestion{Micro-Blackjack \source{CS188, Spring 2014}}

A card-playing program plays Micro-Blackjack. It repeatedly draws a card (with replacement), equally likely to be a 2, 3 or 4, and adds its value to its score, which starts at 0. At each step, if the score is lower than 6, the program can either \enquote{draw} ($d$) or \enquote{cash} ($c$). Otherwise, it can only cash. When it cashes, the game stops and its utility is equal to its score (up to 5) plus 1, or zero if the score is 6 or higher. Until it cashes and after it, it receives no reward. There is no discount ($\gamma = 1$).

\begin{parts}
    \part Formalize Micro-Blackjack as an MDP.

    \begin{solution}
        A state $s = (s_1, s_2)$ holds the score $s_1 \in \{0, 2, 3, 4, 5, 6{+}\}$ (all scores of 6 or more behave alike) and whether the program has cashed, $s_2 \in \{0, 1\}$. The states with $s_2 = 1$ are terminal. The available actions are
        \begin{align*}
            \mathcal{A}(s) & = \begin{cases}
                \cbk{d, c} & \text{if } s_1 < 6 \text{ and } s_2 = 0, \\
                \cbk{c} & \text{if } s_1 \geq 6 \text{ and } s_2 = 0, \\
                \cbk{} & \text{otherwise,}
            \end{cases}
        \end{align*}
        and the transition model and the reward function are
        \begin{align*}
            P(s' = (s_1', s_2') \mid s = (s_1, s_2), a) & = \begin{cases}
                1 & \text{if } a = c, \ s_1' = s_1 \text{ and } s_2' = 1, \\
                \frac{1}{3} & \text{if } a = d, \ s_1' - s_1 \in \cbk{2, 3, 4} \text{ and } s_2' = 0, \\
                0 & \text{otherwise,}
            \end{cases} \\
            R(s = (s_1, s_2)) & = \begin{cases}
                s_1 + 1 & \text{if } s_1 < 6 \text{ and } s_2 = 1, \\
                0 & \text{otherwise.}
            \end{cases}
        \end{align*}
    \end{solution}

    \part Derive the optimal policy for this MDP.

    \begin{solution}
        The value $V(s)$ of a state, its maximum expected utility, satisfies the Bellman equation
        \begin{equation*}
            V(s) = R(s) + \gamma \max_{a \in \mathcal{A}(s)} \sum_{s'} P(s' \mid s, a) V(s'),
        \end{equation*}
        and the optimal policy is $\pi^*(s) = \arg \max_{a \in \mathcal{A}(s)} \sum_{s'} P(s' \mid s, a) V(s')$. Since no action is available in the terminal states, their value is their reward, $V((s_1, 1)) = R((s_1, 1))$. We can apply either value iteration or policy iteration.

        \begin{itemize}
            \item In value iteration, we start from $V_0(s) = R(s)$ and repeat the Bellman update
            \begin{equation*}
                V_{i+1}(s) = R(s) + \gamma \max_{a \in \mathcal{A}(s)} \sum_{s'} P(s' \mid s, a) V_{i}(s')
            \end{equation*}
            until convergence ($V_{i + 1} = V_i$). Although $\gamma = 1$, it converges, since every game ends: every policy reaches a terminal state within four steps. For example, for the first state of the first iteration, we have
            \begin{align*}
                V_1((0, 0)) &= R((0, 0)) + \gamma \max \left\{ \underbrace{V_0((0, 1))}_{a=c}, \ \underbrace{\tfrac{1}{3} V_0((2, 0)) + \tfrac{1}{3} V_0((3, 0)) + \tfrac{1}{3} V_0((4, 0))}_{a=d} \right\} \\
                &= 0 + \max \left\{ 1, \ 0 \right\} = 1.
            \end{align*}

            \begin{center}
                \begin{tabular}{ccccccccccccc}
                    \toprule
                    $s_2$ & \multicolumn{6}{c}{0} & \multicolumn{6}{c}{1} \\
                \cmidrule(lr){2-7} \cmidrule(lr){8-13}
                $s_1$ & 0 & 2 & 3 & 4 & 5 & $6+$ & 0 & 2 & 3 & 4 & 5 & $6+$ \\
                \midrule
                    $V_0(s)$ & 0 & 0 & 0 & 0 & 0 & 0 & 1 & 3 & 4 & 5 & 6 & 0 \\
                    $V_1(s)$ & 1 & 3 & 4 & 5 & 6 & 0 & 1 & 3 & 4 & 5 & 6 & 0 \\
                    $V_2(s)$ & 4 & $\frac{11}{3}$ & 4 & 5 & 6 & 0 & 1 & 3 & 4 & 5 & 6 & 0 \\
                    $V_3(s)$ & $\frac{38}{9}$ & $\frac{11}{3}$ & 4 & 5 & 6 & 0 & 1 & 3 & 4 & 5 & 6 & 0 \\
                    $V_4(s)$ & $\frac{38}{9}$ & $\frac{11}{3}$ & 4 & 5 & 6 & 0 & 1 & 3 & 4 & 5 & 6 & 0 \\
                    \bottomrule
                \end{tabular}
            \end{center}

            Each iteration takes $\mathcal{O}(\abs{\mathcal{S}}^2 \abs{\mathcal{A}})$ operations. The optimal policy follows from the values:
            \begin{center}
                \begin{tabular}{ccccccccccccc}
                    \toprule
                    $s_2$ & \multicolumn{6}{c}{0} & \multicolumn{6}{c}{1} \\
                \cmidrule(lr){2-7} \cmidrule(lr){8-13}
                $s_1$ & 0 & 2 & 3 & 4 & 5 & $6+$ & 0 & 2 & 3 & 4 & 5 & $6+$ \\
                \midrule
                    $\pi^*(s)$ & $d$ & $d$ & $c$ & $c$ & $c$ & $c$ & \multicolumn{6}{c}{$-$} \\
                    \bottomrule
                \end{tabular}
            \end{center}

            \item In policy iteration, we start from a policy $\pi_0$, evaluate it by solving the linear equations
            \begin{equation*}
                V^{\pi_i}(s) = R(s) + \gamma \sum_{s'} P(s' \mid s, \pi_i(s)) V^{\pi_i}(s'),
            \end{equation*}
            and improve it with $\pi_{i+1}(s) = \arg \max_{a \in \mathcal{A}(s)} \sum_{s'} P(s' \mid s, a) V^{\pi_i}(s')$, until the policy no longer changes. Here, the equations are triangular, since the score only increases, and are solved from the highest score down.

            With $\pi_0(s) = c$ everywhere, $V^{\pi_0}((s_1, 0)) = s_1 + 1$ for $s_1 < 6$ and $V^{\pi_0}((6{+}, 0)) = 0$. Improving it, drawing from $(0, 0)$ is worth $\frac{1}{3}(3 + 4 + 5) = 4 > 1$, from $(2, 0)$ it is worth $\frac{1}{3}(5 + 6 + 0) = \frac{11}{3} > 3$, and from $(3, 0)$ only $\frac{1}{3}(6 + 0 + 0) = 2 < 4$; drawing from $(4, 0)$ or $(5, 0)$ always busts. Hence $\pi_1 = (d, d, c, c, c, c)$ for $s_1 = 0, 2, 3, 4, 5, 6{+}$.

            Evaluating $\pi_1$ from the highest score down gives $V^{\pi_1}((5, 0)) = 6$, $V^{\pi_1}((4, 0)) = 5$, $V^{\pi_1}((3, 0)) = 4$, $V^{\pi_1}((2, 0)) = \frac{1}{3}(5 + 6 + 0) = \frac{11}{3}$ and $V^{\pi_1}((0, 0)) = \frac{1}{3}(\frac{11}{3} + 4 + 5) = \frac{38}{9}$. Improving $\pi_1$ changes no action ($\frac{38}{9} > 1$, $\frac{11}{3} > 3$, $2 < 4$), so that $\pi_2 = \pi_1 = \pi^*$, the policy found by value iteration.

            For large problems, solving the linear equations exactly costs $\mathcal{O}(\abs{\mathcal{S}}^3)$ operations; \emph{modified} policy iteration then replaces the exact evaluation by a few simplified Bellman updates $V_{j+1}(s) = R(s) + \gamma \sum_{s'} P(s' \mid s, \pi_i(s)) V_j(s')$.
        \end{itemize}
    \end{solution}
\end{parts}

\titledquestion{Overheating machine}

A maintenance robot looks after a machine that may overheat. It cannot measure the temperature directly: every hour, it only checks whether the machine's alarm is on, and decides whether to cool the machine for the next hour. The alarm is on with probability 0.8 when the machine is overheating, and with probability 0.1 when it is not. Cooling costs 5 (energy), whereas leaving an overheating machine without cooling for an hour costs 10 (wear). Between two checks, a machine that is not overheating starts overheating with probability 0.2, an overheating machine that is not cooled keeps overheating, and a machine that has been cooled is no longer overheating at the next check. When the robot starts, the machine is overheating with probability 0.5.

\begin{parts}
    \part Draw the dynamic decision network of this problem, as well as its conditional probability tables and its reward function.

    \begin{solution}
        Let $H_t \in \cbk{0, 1}$ indicate whether the machine is overheating at time $t$, $E_t \in \cbk{0, 1}$ whether the alarm is on, and $F_t \in \cbk{0, 1}$ whether the robot cools the machine. The reward is $R_t \in \cbk{0, -5, -10}$. The alarm is observed, and the decision depends on it.

                \node[random variable] (H1) at (3.6, 0) {$H_{t+1}$};
                \node[observed variable] (E) at (0, -2) {$E_t$};
                \node[decision variable] (F) at (1.8, -2) {$F_t$};
                \node[utility variable] (R) at (1.8, -3.8) {$R_t$};
                \draw[dependency] (H) -- (H1);
                \draw[dependency] (H) -- (E);

                \draw[dependency] (F) -- (H1);
                \draw[dependency] (F) -- (R);
                \draw[dependency] (H) to[out=-150, in=180] (R);
            \end{tikzpicture}
        \end{center}

        \begin{center}
            \begin{tabular}{cc}
                \toprule
                $H_t$ & $P(E_t = 1 \mid H_t)$ \\
                \midrule
                0 & 0.1 \\
                1 & 0.8 \\
                \bottomrule
            \end{tabular}
            \qquad
            \begin{tabular}{cccc}
                \toprule
                $H_t$ & $F_t$ & $P(H_{t+1} = 1 \mid H_t, F_t)$ & $R_t(H_t, F_t)$ \\
                \midrule
                0 & 0 & 0.2 & 0 \\
                1 & 0 & 1 & $-10$ \\
                0 & 1 & 0 & $-5$ \\
                1 & 1 & 0 & $-5$ \\
                \bottomrule
            \end{tabular}
        \end{center}

        For completeness we also have to define the prior $P(H_0 = 1) = 0.5$. Note that $R_t$ is a deterministic function of $H_t$ and $F_t$.
    \end{solution}

    \part Give the sequence of belief states if the robot observes the alarm and acts as follows: $(e_t, f_t) = (0, 0)$, $(1, 1)$, $(0, 0)$, $(0, 0)$ for $t = 0, 1, 2, 3$.

    \begin{solution}
        The environment is only partially observable (POMDP): the robot does not know the current state $s = H_t$, but perceives $e = E_t$ through the sensor model $P(e \mid s)$ and acts $a = F_t$. If $b$ is the current belief state and the robot does $a$ and then perceives $e'$, the next belief state is
        \begin{equation*}
            b'(s') = \alpha P(e' \mid s') \sum_s P(s' \mid s, a) b(s).
        \end{equation*}
        Here, this gives
        \begin{align*}
            b_{t+1}(h_{t+1}) & = \alpha P(e_{t+1} \mid h_{t+1}) \sum_{h_t} P(h_{t+1} \mid h_t, f_t) b_t(h_t),
        \end{align*}
        with the initial belief
        \begin{align*}
            b_0 & = P(H_0 \mid e_0) = \alpha P(e_0 \mid H_0) P(H_0).
        \end{align*}
        With $e_{0:3} = f_{0:3} = (0, 1, 0, 0)$ and beliefs written as $(b(0), b(1))$, we have
        \begin{align*}
            b_0 & = \alpha_0 \mat{0.9 & 0 \\ 0 & 0.2} \mat{0.5 \\ 0.5} \approx \mat{0.8182 \\ 0.1818} \\
            b_1 & = \alpha_1 \mat{0.1 & 0 \\ 0 & 0.8} \mat{0.8 & 0 \\ 0.2 & 1} b_0 \approx \mat{0.1915 \\ 0.8085} \\
            b_2 & = \alpha_2 \mat{0.9 & 0 \\ 0 & 0.2} \mat{1 & 1 \\ 0 & 0} b_1 = \mat{1 \\ 0} \\
            b_3 & = \alpha_3 \mat{0.9 & 0 \\ 0 & 0.2} \mat{0.8 & 0 \\ 0.2 & 1} b_2 \approx \mat{0.9474 \\ 0.0526} .
        \end{align*}
    \end{solution}

    \part From the sequence of belief states, determine the sequence of expected rewards.

    \begin{solution}
        The expected reward of a belief state $b$ is $\rho(b) = \sum_s b(s) R(s)$. Here, the reward also depends on the action:
        \begin{equation*}
            \rho_t = \sum_{h_t} R_t(h_t, f_t) b_t(h_t).
        \end{equation*}
        Then,
        \begin{align*}
            \rho_0 & = \mat{0 & -10} b_0 \approx -1.818 \\
            \rho_1 & = \mat{-5 & -5} b_1 = -5 \\
            \rho_2 & = \mat{0 & -10} b_2 = 0 \\
            \rho_3 & = \mat{0 & -10} b_3 \approx -0.526 .
        \end{align*}
    \end{solution}
\end{parts}

\titledquestion{Pursuit evasion \source{CS188, Spring 2014}}

Pacman is trapped in the 2 by 2 maze below with a hungry ghost. When it is its turn to move, Pacman must move one step horizontally or vertically to a neighboring square. When it is the ghost's turn, it must also move one step horizontally or vertically. The ghost and Pacman alternate moves. After every move (by either the ghost or Pacman), if Pacman and the ghost occupy the same square, Pacman is eaten and receives a utility of \num{-100}. Otherwise, it receives a utility of \num{1}. The ghost attempts to minimize the utility that Pacman receives. Pacman makes the first move. The game is not guaranteed to terminate.

\begin{center}
    \begin{tikzpicture}[world diagram, x=1cm, y=1cm]
        \draw[grid lines] (0, 0) grid (2, 2);
        \draw[world border] (0, 0) rectangle (2, 2);
        \pic at (0.5, 1.5) {ghost};
        \pic at (0.5, 0.5) {pacman};
    \end{tikzpicture}
\end{center}

For example, with a discount factor of $\gamma = 1$, if Pacman moves right, ghost moves down, then Pacman moves left, Pacman earns a reward of 1 initially ($R(s_0)$) and after the first two moves and \num{-100} after the last move, for a total utility of \num{-97}.

\begin{parts}
    \part Assume a discount factor $\gamma = 0.5$, where the discount factor is applied once every time either Pacman or the ghost moves. What is the Minimax value of the complete (infinite) game?

    \begin{solution}
        If we assume the game starts from the displayed state $s_0$, Pacman always has an action to get out of reach of the ghost. Hence, if Pacman is optimal, which is true by definition in Minimax, it never gets eaten. Therefore, we can compute the initial state value
        \begin{equation*}
            V(s_0) = \sum_{t = 0}^\infty \gamma^t \underbrace{R(s_t)}_{1} = \lim_{t \to \infty} \frac{1 - \gamma^{t+1}}{1 - \gamma} = \frac{1}{1 - \gamma} = 2 ,
        \end{equation*}
        without actually building the (infinite) Minimax tree.
    \end{solution}

    \part Why are the value/policy iteration algorithms superior to Minimax for solving this game?

    \begin{solution}
        If $\gamma < 1$, we know that the value/policy iteration algorithms converge toward a fixed point, even if the game does not terminate. Conversely, Minimax is not guaranteed to terminate due to its recursivity.
    \end{solution}

    \uplevel{This game is similar to an MDP because rewards are earned at every timestep. However, it is also an adversarial game involving decisions by two agents. Let $s$ be the state (\eg{} the positions of Pacman and the ghost and who is playing) and let $\mathcal{A}(s)$ be the set of actions available to the player in state $s$. Let $s' = T(s, a)$ denote the successor of a state $s$ resulting from the action $a$. Finally, let $R(s)$ denote the utility received after moving to state $s$.}

    \part Write down an expression (analogous to Bellman equation) for $V(s)$, the value of the current state if it is Pacman's turn.

    \begin{solution}
        \begin{equation*}
            V(s) = R(s) + \gamma \max_{a \in \mathcal{A}(s)} \sbk*{ R(T(s, a)) + \gamma \min_{a' \in \mathcal{A}(T(s, a))} V(T(T(s, a), a')) }
        \end{equation*}
    \end{solution}
\end{parts}

Assuming a discount factor $\gamma = 1$,

\begin{parts}
    \part Perform direct utility estimation of the expected utilities $V^\pi(s)$, given the first four trials, averaging the rewards-to-go observed at every visit of each state.

    \begin{solution}
        In this setting, the transition model $P(s' \mid s, a)$ and the reward function $R(s)$ are unknown. We wish to learn the expected utility $V^\pi$ of the policy $\pi$ without modeling the environment, \ie{} without building approximates $\hat{P}(s' \mid s, a)$ and $\hat{R}(s)$. The principle of direct utility estimation is to approximate $V^\pi(s)$ by the average utility $\hat{V}(s)$ of the state $s$ within all trial trajectories, \ie{}
        \begin{equation*}
            \hat{V}(s) = \frac{1}{N(s)} \sum_{(i, j) \in I(s)} \sum_{t = 0}^{\infty} \gamma^t r^i_{j + t} \approx V^\pi(s) = \left. \E \sbk*{\sum_{t = 0}^{\infty} \gamma^t R(s_t)} \right|_{s_0 = s}
        \end{equation*}
        where $I(s) = \cbk{(i, j): s^i_j = s}$ indexes the occurrences of $s$ and $N(s) = \abs{I(s)}$ is the number of occurrences of $s$. For example, in our case and excluding the fifth trial,
        \begin{align*}
            I((1, 1)) & = \cbk{(1, 0), (2, 0), (3, 0), (4, 0)} \\
            \hat{V}((1, 1)) & \approx \frac{1}{4} \rbk*{- 1 \, \gamma^3 + 5 \, \gamma^4 - 8 \, \gamma^3 - 1 \, \gamma^5} = \frac{-5}{4} \\
            I((2, 2)) & = \cbk{(1, 2), (2, 2), (3, 2), (4, 2), (4, 4)} \\
            \hat{V}((2, 2)) & \approx \frac{1}{5} \rbk*{- 1 \, \gamma^1 + 5 \, \gamma^2 - 8 \, \gamma^1 - 1 \, \gamma^3 - 1 \, \gamma^1} = \frac{-6}{5} \\
            I((2, 3)) & = \cbk{(1, 3), (4, 5)} \\
            \hat{V}((2, 3)) & \approx \frac{1}{2} \rbk*{- 1 \, \gamma^0 - 1 \, \gamma^0} = -1 .
        \end{align*}
        Importantly, since the agent has not reached the states $(1, 3)$ and $(3, 1)$ yet, it is not possible to estimate their expected utility. Instead, we assume a default value of $0$.

    \part Update the estimated expected utilities with respect to the fifth trial using temporal-difference learning. Assume a learning rate $\alpha = 0.5$.

    \begin{solution}
        Direct utility estimation misses the fact that the expected utilities for different states are not independent, since they obey the Bellman equation for a fixed policy
        \begin{equation*}
            V^\pi(s) = R(s) + \gamma \sum_{s'} P(s' \mid s, \pi(s)) V^\pi(s').
        \end{equation*}
        Then, we would like our estimates $V^\pi(s)$ to verify the Bellman equation, \ie{} to minimize
        \begin{equation*}
            L = \underset{s' \mid s}{\E} \sbk*{\rbk*{R(s) + \gamma V^\pi(s') - V^\pi(s)}^2} .
        \end{equation*}
        One way to reach this objective is to follow the opposite of its gradient
        \begin{equation*}
            \nabla L = 2 \underset{s' \mid s}{\E} \sbk*{V^\pi(s) - R(s) - \gamma V^\pi(s')}
        \end{equation*}
        with respect to $V^\pi(s)$, \ie{} to perform \emph{gradient descent}. Unfortunately, due to the expectation, we don't have access to the true gradient. Instead, we use a \emph{stochastic} approximation of the gradient from observed\footnotemark{} tuples $(s, r, a, s')$ and update $V^\pi(s)$ as
        \begin{align*}
            V^\pi(s) & \leftarrow V^\pi(s) - \alpha \rbk*{V^\pi(s) - r - \gamma V^\pi(s')} \\
            & \leftarrow (1 - \alpha) V^\pi(s) + \alpha \rbk*{r + \gamma V^\pi(s')}
        \end{align*}
        where $\alpha$ is the learning rate. For a fixed learning rate, the average of $V^\pi(s)$ converges towards (oscillates around) the true expected utility $V^\pi(s)$. For a (slowly) decreasing learning rate, $V^\pi(s)$ itself converges to $V^\pi(s)$. For historical reasons, this algorithm is called temporal-difference (TD) learning.

        \footnotetext{We are not limited to one update for each tuple $(s, r, a, s')$. Indeed, as we assume the policy to be stationary, past trials are as likely to happen again as more recent ones. Therefore, reusing tuples several times (in other orders) is a good way to improve estimates while generating fewer trials.}

        Following the trajectory of the fifth trial, we perform the updates
        \begin{align*}
            V^\pi((1, 1)) & \leftarrow (1 - \alpha) V^\pi((1, 1)) + \alpha \rbk*{0 + \gamma V^\pi((1, 2))} = \frac{1}{2} \frac{-5}{4} + \frac{1}{2} \frac{-5}{4} = \frac{-5}{4} \\
            V^\pi((1, 2)) & \leftarrow (1 - \alpha) V^\pi((1, 2)) + \alpha \rbk*{0 + \gamma V^\pi((2, 2))} = \frac{1}{2} \frac{-5}{4} + \frac{1}{2} \frac{-6}{5} = \frac{-49}{40} \\
            V^\pi((2, 2)) & \leftarrow (1 - \alpha) V^\pi((2, 2)) + \alpha \rbk*{0 + \gamma V^\pi((3, 2))} = \frac{1}{2} \frac{-6}{5} + \frac{1}{2} 2 = \frac{2}{5} \\
            V^\pi((3, 2)) & \leftarrow (1 - \alpha) V^\pi((3, 2)) + \alpha \rbk*{0 + \gamma V^\pi((3, 1))} = \frac{1}{2} 2 + \frac{1}{2} 0 = +1 \\
            V^\pi((3, 1)) & \leftarrow (1 - \alpha) V^\pi((3, 1)) + \alpha \rbk*{3 + 0} = \frac{1}{2} 0 + \frac{1}{2} 3 = \frac{+3}{2} .
        \end{align*}

\titledquestion{Q-Learning}

An agent is in an unknown environment where there are three states $\cbk{A, B, C}$ and two actions $\cbk{0, 1}$. We are given the following transitions, generated by taking actions in the environment. Here, the reward depends on the transition, $r = R(s, a, s')$, so that each tuple $(s, a, r, s')$ lists the state, the action, the reward received for the transition and the next state.

\begin{center}
    \begin{tabular}{cccc}
        \toprule
        $s$ & $a$ & $r$ & $s'$ \\
        \midrule
        $A$ & $0$ & $+2$ & $A$ \\
        $C$ & $1$ & $-2$ & $A$ \\
        $B$ & $1$ & $+1$ & $B$ \\
        $A$ & $0$ & $-1$ & $B$ \\
        $B$ & $1$ & $-2$ & $C$ \\
        $C$ & $0$ & $+4$ & $B$ \\
        $B$ & $0$ & $+1$ & $A$ \\
        \bottomrule
    \end{tabular}
\end{center}

Assuming a discount factor $\gamma = 0.5$ and a learning rate $\alpha = 0.75$,

\begin{parts}
    \part Apply the Q-Learning algorithm to obtain state-action-value $Q(s, a)$ estimates, processing the transitions once, in order. Estimates are initialized to $0$.

    \begin{solution}
        As seen in the previous exercise, given trial trajectories of some policy $\pi$, it is possible to estimate its expected utility $V^\pi$ even without knowing the transition model $P(s' \mid s, a)$ or the reward function. However, estimating $V^\pi$ only evaluates the quality of $\pi$, but does not describe how to improve it.

        If we knew the state-action-value $Q(s, a)$ of taking action $a$ in state $s$, we would be able to select the optimal action $\pi^*(s) = \arg \max_a Q(s, a)$ without the transition model, where, with rewards on transitions,
        \begin{equation*}
            Q(s, a) = \sum_{s'} P(s' \mid s, a) \left[ R(s, a, s') + \gamma \max_{a'} Q(s', a') \right].
        \end{equation*}
        Q-Learning learns these values in a model-free fashion, with the update
        \begin{equation*}
            Q(s, a) \leftarrow (1 - \alpha) Q(s, a) + \alpha \rbk*{r + \gamma \max_{a'} Q(s', a')}
        \end{equation*}
        for each observed transition $(s, a, r, s')$. In our case, the sequence of updates is
        \begin{align*}
            Q(A, 0) & \leftarrow \tfrac{1}{4} \cdot 0 + \tfrac{3}{4} \rbk*{+2 + \tfrac{1}{2} \max \cbk{Q(A, 0), Q(A, 1)}} = \frac{3}{2} \\
            Q(C, 1) & \leftarrow \tfrac{1}{4} \cdot 0 + \tfrac{3}{4} \rbk*{-2 + \tfrac{1}{2} \max \cbk{Q(A, 0), Q(A, 1)}} = -\frac{15}{16} \\
            Q(B, 1) & \leftarrow \tfrac{1}{4} \cdot 0 + \tfrac{3}{4} \rbk*{+1 + \tfrac{1}{2} \max \cbk{Q(B, 0), Q(B, 1)}} = \frac{3}{4} \\
            Q(A, 0) & \leftarrow \tfrac{1}{4} \cdot \frac{3}{2} + \tfrac{3}{4} \rbk*{-1 + \tfrac{1}{2} \max \cbk{Q(B, 0), Q(B, 1)}} = -\frac{3}{32} \\
            Q(B, 1) & \leftarrow \tfrac{1}{4} \cdot \frac{3}{4} + \tfrac{3}{4} \rbk*{-2 + \tfrac{1}{2} \max \cbk{Q(C, 0), Q(C, 1)}} = -\frac{21}{16} \\
            Q(C, 0) & \leftarrow \tfrac{1}{4} \cdot 0 + \tfrac{3}{4} \rbk*{+4 + \tfrac{1}{2} \max \cbk{Q(B, 0), Q(B, 1)}} = 3 \\
            Q(B, 0) & \leftarrow \tfrac{1}{4} \cdot 0 + \tfrac{3}{4} \rbk*{+1 + \tfrac{1}{2} \max \cbk{Q(A, 0), Q(A, 1)}} = \frac{3}{4}.
        \end{align*}
        Hence $Q(A, 0) = -\frac{3}{32}$, $Q(A, 1) = 0$, $Q(B, 0) = \frac{3}{4}$, $Q(B, 1) = -\frac{21}{16}$, $Q(C, 0) = 3$ and $Q(C, 1) = -\frac{15}{16}$, so that the greedy policy is $\pi(A) = 1$, $\pi(B) = 0$, $\pi(C) = 0$. As for temporal-difference learning, we are not limited to one update for each tuple: reusing the tuples several times (in other orders) is a good way to reach convergence faster while generating fewer trials.
    \end{solution}

    \part We now switch to a feature-based estimator $Q(s, a) = w_0 + w_1 f_1(s, a)$, with $f_1(s, a) = 2 a - 1$. Starting from weights $w_0 = w_1 = 0$, update the weights according to the approximate Q-Learning algorithm, processing the transitions once, in order.

    \begin{solution}
        We would like our estimates $Q(s, a)$ to satisfy the Bellman equation, \ie{} to minimize
        \begin{equation*}
            L = \underset{s' \mid s, a}{\E} \sbk*{\rbk*{R(s, a, s') + \gamma \max_{a'} Q(s', a') - Q(s, a)}^2} .
        \end{equation*}
        To reach this objective we follow the opposite of its gradient with respect to the weights\footnotemark{} $\mathbf{w} = (w_0, w_1)$ of $Q(s, a)$. Due to the expectation, we use a stochastic approximation of the gradient from each observed transition $(s, a, r, s')$, and update the weights as
        \begin{equation*}
            \mathbf{w} \leftarrow \mathbf{w} + \alpha \rbk*{r + \gamma \max_{a'} Q(s', a') - Q(s, a)} \nabla_{\mathbf{w}} Q(s, a),
        \end{equation*}
        where $\nabla_{\mathbf{w}} Q(s, a) = (1, f_1(s, a)) = (1, 2a - 1)$.
        For instance, the first two updates are
        \begin{align*}
            \mathbf{w} & \leftarrow \mat{0 \\ 0} + \frac{3}{4} \rbk*{2 + \frac{1}{2} \max\cbk{0, 0} - 0} \mat{1 \\ -1} = \mat{\frac{3}{2} \\ -\frac{3}{2}}, \\
            \mathbf{w} & \leftarrow \mat{\frac{3}{2} \\ -\frac{3}{2}} + \frac{3}{4} \rbk*{-2 + \frac{1}{2} \max\cbk{3, 0} - 0} \mat{1 \\ 1} = \mat{\frac{9}{8} \\ -\frac{15}{8}},
        \end{align*}
        since then $Q(A, 0) = w_0 - w_1 = 3$, $Q(A, 1) = 0$ and $Q(C, 1) = w_0 + w_1 = 0$. All the updates are, with the target $r + \gamma \max_{a'} Q(s', a')$:
        \begin{center}
            \begin{tabular}{cccccc}
                \toprule
                $(s, a, r, s')$ & $f_1(s, a)$ & $Q(s, a)$ & Target & $w_0$ & $w_1$ \\
                \midrule
            $(A, 0, +2, A)$ & $-1$ & $0$ & $2$ & $\frac{3}{2}$ & $-\frac{3}{2}$ \\
            $(C, 1, -2, A)$ & $+1$ & $0$ & $-\frac{1}{2}$ & $\frac{9}{8}$ & $-\frac{15}{8}$ \\
            $(B, 1, +1, B)$ & $+1$ & $-\frac{3}{4}$ & $\frac{5}{2}$ & $\frac{57}{16}$ & $\frac{9}{16}$ \\
            $(A, 0, -1, B)$ & $-1$ & $3$ & $\frac{17}{16}$ & $\frac{135}{64}$ & $\frac{129}{64}$ \\
            $(B, 1, -2, C)$ & $+1$ & $\frac{33}{8}$ & $\frac{1}{16}$ & $-\frac{15}{16}$ & $-\frac{33}{32}$ \\
            $(C, 0, +4, B)$ & $-1$ & $\frac{3}{32}$ & $\frac{259}{64}$ & $\frac{519}{256}$ & $-\frac{1023}{256}$ \\
            $(B, 0, +1, A)$ & $-1$ & $\frac{771}{128}$ & $\frac{1027}{256}$ & $\frac{531}{1024}$ & $-\frac{2547}{1024}$ \\
                \bottomrule
            \end{tabular}
        \end{center}

        \footnotetext{The target $r + \gamma \max_{a'} Q(s', a')$ is treated as a constant when taking the gradient. In practice, it is not, since modifying the weights of a parametric function $Q$ modifies all state-action pairs $(s, a)$ at once, which can make approximate Q-Learning unstable.}
    \end{solution}

    \part Why can this estimator not represent the Q-values of (a)?

    \begin{solution}
        The feature $f_1(s, a) = 2a - 1$ ignores the state: the estimator gives the same value $w_0 - w_1$ to action $0$ in every state, and $w_0 + w_1$ to action $1$, whereas the Q-values of (a) differ from one state to another. Its greedy policy takes the same action everywhere. Features that depend on $s$ are needed to tell the states apart.
    \end{solution}
\end{parts}

            & \leftarrow 0.75 \times 2.5 + 0.25 \rbk{3 + 0.75 \max \cbk{2.5, 0}} = 3.094 \\
            Q(\A, \S) & \leftarrow (1 - \alpha) Q(\A, \S) + \alpha \rbk*{R(\A, \S, \F) + \gamma \max_{a'} Q(\F, a')} \\
            & \leftarrow 0.75 \times 0 + 0.25 \rbk{-10 + 0} = -2.5 \\
            Q(\A, \P) & \leftarrow (1 - \alpha) Q(\A, \P) + \alpha \rbk*{R(\A, \P, \C) + \gamma \max_{a'} Q(\C, a')} \\
            & \leftarrow 0.75 \times 0 + 0.25 \rbk{2 + 0.75 \max \cbk{0, 3.094}} = 1.080 \\
            Q(\C, \P) & \leftarrow 0.75 \times 0 + 0.25 \rbk{R(\C, \P, \C) + 0.75 \max \cbk{0, 3.094}} = 0.25 \rbk{1 + 2.320} = 0.830 \\
            Q(\A, \P) & \leftarrow 0.75 \times 1.080 + 0.25 \rbk{R(\A, \P, \C) + 0.75 \max \cbk{0.830, 3.094}} = 1.890 \\
            Q(\A, \S) & \leftarrow 0.75 \times (-2.5) + 0.25 \rbk{R(\A, \S, \F) + 0} = -4.375 \\
            Q(\C, \P) & \leftarrow 0.75 \times 0.830 + 0.25 \rbk{R(\C, \P, \F) + 0} = 0.123 .
        \end{align*}
        Hence $Q(\C, \S) = 3.094$, $Q(\C, \P) = 0.123$, $Q(\A, \S) = -4.375$ and $Q(\A, \P) = 1.890$.
    \end{solution}

    \part Determine the optimal policy according to the state-action-value estimates.

    \begin{solution}
        Taking the action of highest $Q(s, a)$ in each state, since $3.094 > 0.123$ and $1.890 > -4.375$,
        \begin{equation*}
            \pi(s) = \begin{cases}
                \S & \text{if } s = \C \\
                \P & \text{if } s = \A
            \end{cases}
        \end{equation*}
    \end{solution}

    \part None of the selected transitions is a goal scored from away, $(\A, \S, \G)$, worth $+20$. Should the team trust the policy of (c) in state \A? How could the coaching program learn more?

    \begin{solution}
        Not entirely. All the observed shots from \A{} failed, so that $Q(\A, \S)$ is negative, and a robot that follows the greedy policy $\pi(\A) = \P$ will never shoot from away again: it will never observe the goal worth $+20$ that a shot from \A{} can score, and its estimate of $Q(\A, \S)$ will never improve. Q-Learning converges to the optimal Q-values only if every action keeps being tried. The program should therefore explore, for instance by acting $\epsilon$-greedily (shooting from \A{} with a small probability $\epsilon$), or with an exploration function such as $f(v, n) = v + K/n$, which makes it optimistic about the actions it has tried only $n$ times.
    \end{solution}
\end{parts}

\titledquestion{Contraction of the Bellman update \aima{17}}

Let $B$ denote the Bellman update, which maps a utility function $V$ to the function
\begin{equation*}
    (B V)(s) = R(s) + \gamma \max_{a \in \mathcal{A}(s)} \sum_{s'} P(s' \mid s, a) V(s').
\end{equation*}
The Bellman update is a contraction, which guarantees the convergence of value iteration for $\gamma < 1$.

\begin{parts}
    \part Show that, for any two functions $f: \mathcal{X} \to \R$ and $g: \mathcal{X} \to \R$ over a finite set $\mathcal{X}$,
    \begin{equation*}
        \abs{\max_x f(x) - \max_x g(x)} \leq \max_x \, \abs{f(x) - g(x)} .
    \end{equation*}

    \begin{solution}
        Suppose, without loss of generality, that $\max_x f(x) \geq \max_x g(x)$, and let $x^*$ be a maximizer of $f$. Then
        \begin{equation*}
            \abs{\max_x f(x) - \max_x g(x)} = f(x^*) - \max_x g(x) \leq f(x^*) - g(x^*) \leq \max_x \abs{f(x) - g(x)} .
        \end{equation*}
    \end{solution}

    \part Apply the previous result to prove that the Bellman update is a contraction of factor $\gamma$, that is, for any two utility functions $V, V': \mathcal{S} \to \R$,
    \begin{equation*}
        \norm{B V - B V'}_\infty \leq \gamma \norm{V - V'}_\infty ,
    \end{equation*}
    where $\norm{V}_\infty = \max_s \abs{V(s)}$.

    \begin{solution}
        The rewards cancel, and (a) applies to the maximum over the actions:
        \begin{align*}
            \norm{B V - B V'}_\infty
            & = \gamma \max_s \abs{\max_a \sum_{s'} P(s' \mid s, a) V(s') - \max_a \sum_{s'} P(s' \mid s, a) V'(s')} \\
            & \leq \gamma \max_s \max_a \abs{\sum_{s'} P(s' \mid s, a) (V(s') - V'(s'))} \\
            & \leq \gamma \max_s \max_a \sum_{s'} P(s' \mid s, a) \abs{V(s') - V'(s')} \\
            & \leq \gamma \max_s \max_a \sum_{s'} P(s' \mid s, a) \norm{V - V'}_\infty = \gamma \norm{V - V'}_\infty ,
        \end{align*}
        since the probabilities $P(s' \mid s, a)$ sum to $1$ over $s'$.
    \end{solution}
\end{parts}

\titledquestion{Discount factor \aima{17}}

Consider the $101 \times 3$ world below. In the start state, of reward $0$, the agent has a choice of two deterministic actions, \texttt{up} or \texttt{down}, but in the other states the agent has one deterministic action, \texttt{right}, until it leaves the world at the right end. Assuming a discounted reward function, compute the utility of each action as a function of $\gamma$. For what values of the discount factor $\gamma$ should the agent choose \texttt{up} and for which \texttt{down}?

\begin{center}
    \begin{tikzpicture}[world diagram, x=0.9cm, y=0.9cm]
        \draw[grid lines] (0, 0) grid (6, 3);
        \fill[white] (4.05, -0.05) rectangle (4.95, 3.05);
        \draw[world border] (0, 0) rectangle (6, 3);
        \node at (0.5, 1.5) {$0$};
        \node at (1.5, 2.5) {$+50$};
        \node at (1.5, 0.5) {$-50$};
        \foreach \x in {2.5, 3.5, 5.5} {
            \node at (\x, 2.5) {$-1$};
            \node at (\x, 0.5) {$+1$};
        }
        \node at (4.5, 2.5) {$\cdots$};
        \node at (4.5, 0.5) {$\cdots$};
        \node[diagram caption, anchor=east] at (-0.1, 1.5) {start};
        \node[diagram caption] at (3.5, -0.4) {100 squares after the first};
    \end{tikzpicture}
\end{center}

\blindfootnote{This simple example actually reflects many real-world situations in which one must weigh the value of an immediate action versus the potential long-term consequences, such as choosing to dump pollutants into a lake.}

\begin{solution}
    Going \texttt{up}, the agent receives $+50$ after one step, then $-1$ at each of the next $100$ steps; going \texttt{down}, it receives the opposite rewards. Hence
    \begin{align*}
        V(\texttt{up}) & = 50 \gamma - \sum_{t=2}^{101} \gamma^t = 50 \gamma - \gamma^2 \frac{1 - \gamma^{100}}{1 - \gamma}, &
        V(\texttt{down}) & = -V(\texttt{up}).
    \end{align*}
    The agent should choose \texttt{up} when $V(\texttt{up}) > 0$, that is when $50 > \gamma (1 - \gamma^{100}) / (1 - \gamma)$, which holds for $\gamma < 0.9844$ (solved numerically), and \texttt{down} for $\gamma > 0.9844$. A short-sighted agent takes the immediate $+50$; a far-sighted one accepts the immediate $-50$ for the hundred $+1$ that follow.
\end{solution}

\titledquestion{Policy iteration \aima{17}}

Consider an undiscounted MDP having three states, $(1, 2, 3)$, with rewards $-1$, $-2$, $0$, respectively. State 3 is a terminal state. In states 1 and 2 there are two possible actions: $a$ and $b$. The transition model is as follows:

\begin{itemize}
    \item In state 1, action $a$ moves the agent to state 2 with probability $0.8$ and makes the agent stay put with probability $0.2$.
    \item In state 2, action $a$ moves the agent to state 1 with probability $0.8$ and makes the agent stay put with probability 0.2.
    \item In either state 1 or state 2, action $b$ moves the agent to state 3 with probability $0.1$ and makes the agent stay put with probability $0.9$.
\end{itemize}

Answer the following questions:

\begin{parts}
    \part What can be determined \emph{qualitatively} about the optimal policy in states 1 and 2?

    \begin{solution}
        Intuitively, the agent wants to get to state 3 as soon as possible, because it will pay a cost for each time step it spends in states 1 and 2. However, the only action that reaches state 3 (action b) succeeds with low probability, so the agent should minimize the cost it incurs while trying to reach the terminal state. This suggests that the agent should definitely try action $b$ in state 1, but, in state 2, it might be better to try action $a$ to get to state 1, rather than aiming directly for state 3. The decision in state 2 involves a numerical trade-off.
    \end{solution}

    \part Apply policy iteration, showing each step in full, to determine the optimal policy and the values of states 1 and 2. Assume that the initial policy has action $b$ in both states.

    \begin{solution}
        \begin{itemize}
            \item Initialization: $R \leftarrow\langle- 1,-2,0\rangle, \pi_0 \leftarrow\langle b, b\rangle$.
            \item Value determination:
            \[
                \begin{array}{l}{V(s_{1})=-1+0.1 V(s_{3})+0.9 V(s_{1})} \\ {V(s_{2})=-2+0.1 V(s_{3})+0.9 V(s_{2})} \\ {V(s_{3})=0}\end{array}
            \]
            That is, $V(s_1) =-10$ and $V(s_2) =-20$.
            Policy update:
            \begin{itemize}
                \item In state 1,
                $\pi_1(s_1) = a$ leads to $\sum_{i \in \{1, 2, 3\}} P(s_i \mid s_1, a) V(s_i) = 0.8 \times -20 + 0.2 \times -10 = -18$ and $\pi_1(s_1) = b$ leads $\sum_{i \in \{1, 2, 3\}} P(s_i \mid s_1, b) V(s_i) = 0.1 \times 0 + 0.9 \times -10 = -9$, thus $\pi_1(s_1) = b$.

                \item In state 2,
                $\pi_1(s_2) = a$ leads to $\sum_{i \in \{1, 2, 3\}} P(s_i \mid s_2, a) V(s_i) = 0.2 \times -20 + 0.8 \times -10 = -12$ and $\pi_1(s_2) = b$ leads $\sum_{i \in \{1, 2, 3\}} P(s_i \mid s_2, b) V(s_i) = 0.1 \times 0 + 0.9 \times -20 = -18$, thus $\pi_1(s_2) = a$.
            \end{itemize}
            \item Value determination:
            \[
                \begin{array}{l}{V(s_{1})=-1+0.1 V(s_{3})+0.9 V(s_{1})} \\ {V(s_{2})=-2+0.8 V(s_{1})+0.2 V(s_{2})} \\ {V(s_{3})=0}\end{array}
            \]
            That is, $V(s_1) =-10$ and $V(s_2) = -12.5$.
            Policy update:
            \begin{itemize}
                \item In state 1,
                $\pi_2(s_1) = a$ leads to $\sum_{i \in \{1, 2, 3\}} P(s_i \mid s_1, a) V(s_i) = 0.8 \times -12.5 + 0.2 \times -10 = -12$ and $\pi_2(s_1) = b$ leads $\sum_{i \in \{1, 2, 3\}} P(s_i \mid s_1, b) V(s_i) = 0.1 \times 0 + 0.9 \times -10 = -9$, thus $\pi_2(s_1) = b$.

                \item In state 2,
                $\pi_2(s_2) = a$ leads to $\sum_{i \in \{1, 2, 3\}} P(s_i \mid s_2, a) V(s_i) = 0.2 \times -12.5 + 0.8 \times -10 = -10.5$ and $\pi_2(s_2) = b$ leads $\sum_{i \in \{1, 2, 3\}} P(s_i \mid s_2, b) V(s_i) = 0.1 \times 0 + 0.9 \times -12.5 = -11.25$, thus $\pi_2(s_2) = a$.
            \end{itemize}
            \item Unchanged, which implies convergence.
        \end{itemize}
    \end{solution}

    \part What happens to policy iteration if the initial policy has action $a$ in both states? Does discounting help? Does the optimal policy depend on the discount factor?

    \begin{solution}
        An initial policy with action $a$ in both states leads to an unsolvable problem. The initial value determination problem has the form \[\begin{array}{l}{u_{1}=-1+0.2 u_{1}+0.8 u_{2}} \\ {u_{2}=-2+0.8 u_{1}+0.2 u_{2}} \\ {u_{3}=0}\end{array}\] and the first two equations are inconsistent. If we were to try to solve them iteratively, we would find the values tending to $-\infty$. Discounting leads to well-defined solutions by bounding the penalty (expected discounted cost) an agent can incur at either state. However, the choice of discount factor will affect the policy that results. For $\gamma$ small, the cost incurred in the distant future plays a negligible role in the value computation, because $\gamma^n$ is near $0$. As a result, an agent could choose action $b$ in state 2 because the discounted short-term cost of remaining in the non-terminal states (states 1 and 2) outweighs the discounted long-term cost of action $b$ failing repeatedly and leaving the agent in state 2.
    \end{solution}
\end{parts}
